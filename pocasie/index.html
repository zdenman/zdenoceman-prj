O Appke

It's fully functional weather app with 3 days forecast. Currently can be installed on desktop or mobile as PWA (progressive web application). It has 5 color themes and comes in 3 languages English, Slovak and Serbian.

Developed in javaScript/jQuery by Zdeno Ceman

All wether data is provided by WeatherAPI.com

Weather icons are made by Basmilius Github
